## 1. 功能概述

用户信息管理模块分为两个子系统：

| 子系统 | 目标用户 | 主要功能 |
|--------|---------|---------|
| 用户端个人信息管理 | 普通用户 | 查看和编辑个人资料、修改密码、注销账号 |
| 后台用户管理 | 管理员 | 用户列表、用户详情、状态管理、密码重置、删除用户 |

### 4.2 订单统计实现

```java
public UserOrderStats getUserOrderStats(Long userId) {
    // 统计作为买家的订单数量
    long buyerOrders = orderRepository.countByBuyerId(userId);

    // 统计作为卖家的订单数量
    long sellerOrders = orderRepository.countBySellerId(userId);

    long completedAsBuyer = orderRepository.countByBuyerIdAndStatus(
        userId, Order.OrderStatus.COMPLETED);

        userId, Order.OrderStatus.COMPLETED);

    return new UserOrderStats(
        buyerOrders, sellerOrders, completedAsBuyer + completedAsSeller);
}
```

## 5. 遇到的问题与解决方案

### 5.1 前后端 API 路径重复问题

**问题描述：**
登录时请求地址变成 `/api/api/auth/login`，导致 403 Forbidden 错误。

**原因分析：**
在 `stores/auth.ts` 中，API 请求 URL 包含了 `/api` 前缀，但 `request.ts` 的 `baseURL` 已经设置为 `/api`，导致路径重复。

**错误代码：**
```typescript
// stores/auth.ts - 错误写法
const response = await request.post('/api/auth/login', {...})
```

**解决方案：**
移除所有 API 调用中的 `/api` 前缀，因为 `baseURL` 已经配置。

```typescript
// stores/auth.ts - 正确写法
const response = await request.post('/auth/login', {...})
```

**涉及文件：**
- `frontend/src/stores/auth.ts`
- `frontend/src/views/admin/Register.vue`

### 5.2 用户详情页订单统计为空

**问题描述：**
后台用户详情页的订单统计数据显示为 0。

**原因分析：**
后端没有提供获取用户订单统计的 API，前端也没有调用相关接口。

**解决方案：**

1. **后端 OrderRepository 添加方法：**

```java
long countBySellerIdAndStatus(Long sellerId, OrderStatus status);
```

2. **AdminUserService 添加统计方法：**

```java
@Transactional(readOnly = true)
public UserOrderStats getUserOrderStats(Long userId) {

    long sellerOrders = orderRepository.countBySellerId(userId);
    long completedAsBuyer = orderRepository.countByBuyerIdAndStatus(
        userId, Order.OrderStatus.COMPLETED);

        userId, Order.OrderStatus.COMPLETED);
    return new UserOrderStats(buyerOrders, sellerOrders, 
        completedAsBuyer + completedAsSeller);
}
```

3. **AdminUserController 添加接口：**

4. **前端调用：**

### 5.3 UserDetails 无法获取用户 ID

**问题描述：**
在 Controller 中无法从 `@AuthenticationPrincipal UserDetails` 获取用户 ID，只能获取用户名。

**原因分析：**
`CustomUserDetailsService` 构建 `UserDetails` 时只存储了用户名、密码和权限，没有存储用户 ID。

**解决方案：**
通过用户名查询用户 ID，在 Service 层提供基于用户名的方法。

```java
// UserService.java
@Transactional(readOnly = true)
public UserProfileResponse getProfileByUsername(String username) {
    User user = userRepository.findByUsername(username)
        .orElseThrow(() -> new NotFoundException("用户不存在"));
    return UserProfileResponse.fromUser(user);
}
```

**设计说明：**
采用基于用户名的方法比修改 Spring Security 的认证流程更简单，避免了自定义 Principal 对象的复杂性。

### 5.4 删除账号时的并发问题

**问题描述：**
用户在删除账号时，可能同时有新的订单创建，导致数据不一致。

**解决方案：**
使用 `@Transactional` 注解确保删除操作的原子性，在事务内完成：
1. 密码验证
2. 订单状态检查
3. 状态更新

```java
@Transactional
public void deleteAccountByUsername(String username, String password) {
    User user = userRepository.findByUsername(username)
        .orElseThrow(() -> new NotFoundException("用户不存在"));

    // 验证密码
    if (!passwordEncoder.matches(password, user.getPassword())) {
        throw new UnauthorizedException("密码错误");
    }

    // 检查未完成订单
    for (Order.OrderStatus status : activeStatuses) {
        Page<Order> orders = orderRepository.findByBuyerIdAndStatus(
            user.getId(), status, PageRequest.of(0, 1));
        if (!orders.isEmpty()) {
            throw new ConflictException("存在未完成的订单，无法注销账号");
        }
    }

    // 软删除
    user.setStatus(User.UserStatus.INACTIVE);
    userRepository.save(user);
}
```

### 5.5 H2 数据库连接关闭问题

**问题描述：**
应用重启后 H2 数据库报错：`Database is already closed`

**原因分析：**
H2 内存数据库在 JVM 关闭时自动关闭，如果配置不当会导致数据丢失或连接问题。

**解决方案：**
在 `application.yml` 中配置正确的 H2 参数：

```yaml
spring:
  datasource:
    url: jdbc:h2:mem:aisale;DB_CLOSE_DELAY=-1;DB_CLOSE_ON_EXIT=FALSE
```

**参数说明：**
- `DB_CLOSE_DELAY=-1`：数据库在最后一个连接关闭后不立即关闭
- `DB_CLOSE_ON_EXIT=FALSE`：禁用 JVM 关闭时自动关闭数据库

### 5.6 前端 TypeScript 类型错误

**问题描述：**
1. `ref` 导入但未使用
2. 验证器函数参数 `rule` 未使用导致类型警告

**解决方案：**

1. 移除未使用的导入：
```typescript
// 错误
import { ref, computed, onMounted } from 'vue'
// 正确
import { computed, onMounted } from 'vue'
```

2. 使用 `_` 前缀标记未使用参数：
```typescript
// 错误
const validateConfirmPassword = (rule: any, value: string, callback: Function) => {
// 正确
const validateConfirmPassword = (_rule: any, value: string, callback: Function) => {
```
