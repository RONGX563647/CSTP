## 1. 概述

### 1.1 功能简介

商品推荐模块为用户提供个性化的商品推荐服务。首页默认展示推荐商品而非全部商品，独立的推荐页面提供"为你推荐"、"猜你喜欢"、"新品上架"、"特价折扣"四个推荐维度，并实现了基于多维度综合评分的简易推荐算法。

### 1.2 功能特性

- **首页推荐展示**：首页默认展示精选推荐和综合推荐商品，分类切换"推荐"优先
- **精选推荐横滑**：首页顶部精选推荐区域，支持横向滑动浏览
- **多维推荐标签页**：独立推荐页面提供 4 个推荐维度切换
- **综合推荐算法**：基于推荐标记、销量、浏览量、折扣力度、新品时效等多维度加权评分
- **个性化推荐**：基于用户搜索历史的"猜你喜欢"功能，提取兴趣关键词和偏好分类
- **新品推荐**：14天内新品，随时间衰减加权
- **折扣推荐**：折扣力度排序，折扣越低排越前
- **商品徽标**：精选、折扣、新品标签展示


| 参数 | 类型 | 必填 | 说明 |

| limit | int | 否 | 返回数量（默认20） |

| 参数 | 类型 | 必填 | 说明 |

## 6. 推荐算法详解

### 6.1 综合评分公式

```
score = featured_weight + sales_weight × ln(1 + salesCount)
      + views_weight × ln(1 + viewCount)
      + discount_weight × (1 - discount)
      + new_weight × newFactor
```

### 6.2 权重参数

| 参数 | 值 | 说明 |
|------|---|------|
| `WEIGHT_FEATURED` | 30.0 | 推荐标记权重 |
| `WEIGHT_SALES` | 2.0 | 销量权重（对数缩放） |
| `WEIGHT_VIEWS` | 0.1 | 浏览量权重（对数缩放） |
| `WEIGHT_DISCOUNT` | 25.0 | 折扣权重 |
| `WEIGHT_NEW` | 20.0 | 新品权重 |
| `NEW_DECAY_RATE` | 0.05 | 新品每天衰减系数 |
| `NEW_PRODUCT_DAYS` | 14 | 新品有效期（天） |

### 6.3 新品衰减因子

```
newFactor = max(0, 1 - daysSinceCreated × 0.05)

示例：
  发布当天: newFactor = 1.0  → 加分 = 20.0
  第7天:    newFactor = 0.65 → 加分 = 13.0
  第14天:   newFactor = 0.3  → 加分 = 6.0
  第15天:   newFactor = 0    → 加分 = 0.0
```

### 6.4 个性化推荐流程

```
1. 获取用户搜索历史 → 按搜索频次+时间衰减加权排序
2. 取 Top5 兴趣关键词 → 关键词搜索相关商品 (+50分)
3. 提取偏好分类 → 分类热门商品 (+30分)
4. 补充全局精选推荐 (+30分)
5. 合并去重 → 按综合评分排序 → 截取 limit 数量
```

### 6.5 评分示例

| 商品 | 精选 | 销量 | 浏览 | 折扣 | 天数 | 综合得分 |
|------|------|------|------|------|------|---------|
| iPhone 15 | 是 | 50 | 200 | 0.85 | 2 | 30 + 7.8 + 0.8 + 3.75 + 19 = 61.35 |
| MacBook | 否 | 30 | 150 | 0.75 | 10 | 0 + 6.4 + 0.7 + 6.25 + 12 = 25.35 |
| 耳机 | 是 | 10 | 50 | 0.9 | 5 | 30 + 4.8 + 0.5 + 2.5 + 16.5 = 54.3 |

## 7. 使用说明

### 7.1 用户操作流程

1. 打开首页 → 默认展示推荐商品 + 精选横滑
2. 切换分类 → 按分类浏览商品
3. 点击"更多" → 进入独立推荐页面
4. 切换推荐标签 → 为你推荐/猜你喜欢/新品/折扣
5. 点击商品 → 进入商品详情

### 7.2 管理员操作

1. 管理后台设置 `isFeatured=true` → 商品出现在精选推荐
2. 商品折扣自动计算 → 低于8折显示折扣徽标

## 8. 扩展功能

### 8.1 后续可扩展方向

1. **协同过滤推荐**：基于用户-商品交互矩阵的协同过滤算法
2. **实时推荐**：基于用户实时点击流的推荐
3. **A/B测试**：多推荐策略对比实验
4. **推荐解释**：展示推荐理由（"因为你搜索过XX"）
5. **冷启动优化**：新用户注册引导兴趣选择
6. **深度学习推荐**：基于神经网络的推荐模型
7. **推荐位管理**：运营配置推荐位和展示策略

### 8.2 性能优化方向

1. 推荐结果缓存（已实现首页/分类/新品/折扣缓存）
2. 离线计算推荐列表（定时任务预计算）
3. Redis 缓存推荐结果
4. 推荐结果分页加载
