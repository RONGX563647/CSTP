## 二、核心实现原理

### 2.1 消息发送流程 (HTTP)

```
用户点击发送
    ↓
Chat.vue sendMessage()
    ↓
apiSendMessage({ receiverId, content })  ← HTTP POST
    ↓
UserChatController.sendMessage()
    ↓
JwtRequestUtils.getCurrentUserId()  ← 从Token获取发送者ID
    ↓
ChatService.sendMessage()
    ├── 保存消息到数据库
    ├── 发布 ChatMessageEvent (接收方)
    └── 发布 ChatMessageEvent (发送方) ← 多标签页同步
    ↓
HTTP Response 返回 ChatMessageResponse
    ↓
前端添加到消息列表 + 滚动到底部
```

### 2.2 消息推送流程 (WebSocket)

```
ChatMessageEvent 触发
    ↓
ChatMessageEventListener.handleChatMessageEvent()
    ↓
ChatWebSocketHandler.sendMessageToUser()
    ├── 遍历用户的所有WebSocket会话
    └── 逐个发送消息
    ↓
前端 WebSocket onmessage
    ↓
wsService.onMessage() 回调
    ↓
Chat.vue onWebSocketMessage()
    ├── 去重检查 (messages.some(m => m.id === msg.id))
    ├── 添加到消息列表
    └── 标记已读 (如果是对方消息)
```

### 2.3 身份验证流程

```
前端: wsService.connect(token)
    ↓
ws://localhost:8090/ws/chat?token={jwt}
    ↓
JwtHandshakeInterceptor.beforeHandshake()
    ├── 从URL查询参数提取token
    ├── jwtUtil.extractUserId(token)
    ├── jwtUtil.extractUsername(token)
    └── attributes.put("userId", userId)
    ↓
ChatWebSocketHandler.afterConnectionEstablished()
    ├── session.getAttributes().get("userId")
    └── userSessionsMap.put(userId, session)
```

## 三、关键技术实现

### 3.1 Spring Event 事件机制 (解耦循环依赖)

**ChatMessageEvent.java** - 事件定义：
```java
public class ChatMessageEvent extends ApplicationEvent {
    private final Long targetUserId;
    private final ChatMessageResponse message;

    public ChatMessageEvent(Object source, Long targetUserId, ChatMessageResponse message) {
        super(source);
        this.targetUserId = targetUserId;
        this.message = message;
    }

    public Long getTargetUserId() { return targetUserId; }
    public ChatMessageResponse getMessage() { return message; }
}
```

**ChatMessageEventListener.java** - 事件监听：
```java
@Component
@RequiredArgsConstructor
public class ChatMessageEventListener {
    private final ChatWebSocketHandler chatWebSocketHandler;

    @EventListener
    public void handleChatMessageEvent(ChatMessageEvent event) {
        chatWebSocketHandler.sendMessageToUser(event.getTargetUserId(), event.getMessage());
    }
}
```

**ChatService.java** - 使用事件发布：
```java
private final ApplicationEventPublisher eventPublisher;

public ChatMessageResponse sendMessage(Long senderId, Long receiverId, String content) {
    // ... 保存消息 ...

    // 给接收方推送
    eventPublisher.publishEvent(new ChatMessageEvent(this, receiverId, response));
    // 给发送方推送 (支持多标签页)
    eventPublisher.publishEvent(new ChatMessageEvent(this, senderId, response));

    return response;
}
```

### 3.2 多会话管理 (支持多标签页)

```java
// userId -> 该用户的所有活跃WebSocket会话
private final Map<Long, List<WebSocketSession>> userSessionsMap = new ConcurrentHashMap<>();

@Override
public void afterConnectionEstablished(WebSocketSession session) {
    Long userId = (Long) session.getAttributes().get("userId");
    userSessionsMap.computeIfAbsent(userId, k -> new CopyOnWriteArrayList<>()).add(session);
}

@Override
public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
    Long userId = sessionUserMap.remove(session.getId());
    if (userId != null) {
        List<WebSocketSession> sessions = userSessionsMap.get(userId);
        if (sessions != null) {
            sessions.remove(session);
            if (sessions.isEmpty()) {
                userSessionsMap.remove(userId);
            }
        }
    }
}

public void sendMessageToUser(Long userId, ChatMessageResponse message) {
    List<WebSocketSession> sessions = userSessionsMap.get(userId);
    if (sessions == null || sessions.isEmpty()) return;

    for (WebSocketSession session : sessions) {
        if (session.isOpen()) {
            session.sendMessage(new TextMessage(json));
        }
    }
}
```

### 3.3 LocalDateTime 序列化处理

**ChatMessageResponse.java**：
```java
@JsonFormat(pattern = "yyyy-MM-dd'T'HH:mm:ss")
private LocalDateTime createdAt;
```

**websocket.ts** - 前端兼容多种格式：
```typescript
let createdAt = data.createdAt
if (Array.isArray(createdAt)) {
  // Jackson数组格式: [2026,4,14,10,30,0]
  const [y, mo, d, h = 0, mi = 0, s = 0] = createdAt
  createdAt = new Date(y, mo - 1, d, h, mi, s).toISOString()
} else if (typeof createdAt === 'string' && createdAt.includes('T')) {
  // ISO格式: "2026-04-14T10:30:00"
} else {
  createdAt = new Date().toISOString()
}
```

### 3.4 消息去重机制

```typescript
const onWebSocketMessage = (msg: ChatMessage) => {
  const partnerId = currentChatUser.value?.userId

  // 判断是否属于当前聊天
  const isCurrentChatMessage = partnerId && (
    (msg.senderId === partnerId && msg.receiverId === currentUserId.value) ||
    (msg.senderId === currentUserId.value && msg.receiverId === partnerId)
  )

  if (isCurrentChatMessage) {
    // 防止重复添加
    const exists = messages.value.some(m => m.id === msg.id)
    if (!exists) {
      messages.value.push(msg)
      scrollToBottom()
    }

    // 对方消息标记已读
    if (msg.senderId === partnerId) {
      markConversationAsRead(partnerId).catch(() => {})
    }
  }
}
```

@Override
public void afterConnectionEstablished(WebSocketSession session) {
    Long userId = sessionUserMap.get(session.getId());
    List<ChatMessageResponse> unreadMessages = chatService.getUnreadMessages(userId);
    for (ChatMessageResponse msg : unreadMessages) {
        session.sendMessage(new TextMessage(objectMapper.writeValueAsString(msg)));

### 8.2 消息已读回执
```java
public void markAsRead(Long messageId) {
    ChatMessage message = chatMessageRepository.findById(messageId).orElseThrow();
    message.setIsRead(true);
    chatMessageRepository.save(message);

    // 通知发送者
    eventPublisher.publishEvent(new ChatMessageEvent(this, message.getSenderId(),
        ChatMessageResponse.fromEntity(message, ...)));
}
```
