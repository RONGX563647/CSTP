## 1. 后端异常处理体系

### 1.1 设计目标

- **统一性**: 所有异常通过统一格式返回给前端
- **可追溯**: 每个错误有唯一的错误码，便于日志追踪
- **层次化**: 异常按业务/系统分类，便于定位问题
- **用户友好**: 错误消息对用户友好，不暴露内部实现细节

### 1.2 异常层次结构

```
BaseException (项目异常基类，含错误码和 HTTP 状态码)
├── BusinessException (业务异常 - 用户可理解的错误)
│   ├── ValidationException (参数校验失败 - 400)
│   ├── NotFoundException (资源不存在 - 404)
│   ├── ConflictException (状态冲突 - 409)
│   ├── UnauthorizedException (未授权 - 401)
│   └── ForbiddenException (禁止访问 - 403)
├── SystemException (系统异常 - 内部错误)
│   ├── DatabaseException (数据库操作失败 - 500)
│   └── ExternalServiceException (外部服务调用失败 - 503)
└── ApiException (API 通用异常)
    └── RateLimitException (限流 - 429)
```

### 1.3 错误码规范

错误码为 8 位数字，格式：`模块码 (2 位) + 子模块码 (2 位) + 具体错误码 (4 位)`

| 错误码范围 | 模块 | 示例 |
|-----------|------|------|
| 1001xxxx | 通用错误 | 10010001 - 参数校验失败 |
| 2001xxxx | 用户模块 | 20010001 - 用户不存在 |
| 3001xxxx | 商品模块 | 30010001 - 商品不存在 |
| 4001xxxx | 订单模块 | 40010001 - 订单不存在 |
| 5001xxxx | 地址模块 | 50010001 - 地址不存在 |
| 6001xxxx | 评价模块 | 60010001 - 评价不存在 |

#### 1.4.3 GlobalExceptionHandler.java - 全局异常处理器

```java
package com.aisale.backend.handler;

import com.aisale.backend.dto.ErrorResponse;
import com.aisale.backend.exception.BaseException;
import com.aisale.backend.exception.BusinessException;
import com.aisale.backend.exception.SystemException;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {
    
    /**
     * 处理业务异常 - WARN 级别日志
     */
    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ErrorResponse> handleBusinessException(
            BusinessException e, HttpServletRequest request) {
        log.warn("[业务异常] {} - {}", e.getErrorCode().getCode(), e.getMessage());
        
        ErrorResponse errorResponse = ErrorResponse.builder()
            .timestamp(LocalDateTime.now())
            .code(e.getErrorCode().getCode())
            .message(e.getMessage())
            .path(request.getRequestURI())
            .build();
        
        return ResponseEntity
            .status(e.getErrorCode().getHttpStatus())
            .body(errorResponse);
    }
    
    /**
     * 处理系统异常 - ERROR 级别日志 + 堆栈跟踪
     */
    @ExceptionHandler(SystemException.class)
    public ResponseEntity<ErrorResponse> handleSystemException(
            SystemException e, HttpServletRequest request) {
        log.error("[系统异常] {} - {}", e.getErrorCode().getCode(), e.getMessage(), e);
        
        ErrorResponse errorResponse = ErrorResponse.builder()
            .timestamp(LocalDateTime.now())
            .code(e.getErrorCode().getCode())
            .message("系统繁忙，请稍后重试")  // 不暴露内部细节
            .path(request.getRequestURI())
            .build();
        
        return ResponseEntity
            .status(e.getErrorCode().getHttpStatus())
            .body(errorResponse);
    }
    
    /**
     * 处理参数校验异常
     */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> handleValidationException(
            MethodArgumentNotValidException e, HttpServletRequest request) {
        String errorMsg = e.getBindingResult().getFieldErrors().stream()
            .map(error -> error.getField() + ": " + error.getDefaultMessage())
            .collect(Collectors.joining(", "));
        
        log.warn("[参数校验失败] {}", errorMsg);
        
        ErrorResponse errorResponse = ErrorResponse.builder()
            .timestamp(LocalDateTime.now())
            .code(ErrorCode.PARAM_VALIDATION_ERROR.getCode())
            .message(errorMsg)
            .path(request.getRequestURI())
            .build();
        
        return ResponseEntity.badRequest().body(errorResponse);
    }
}
```

### 1.5 Service 层使用示例

```java
@Service
@Slf4j
public class ProductService {
    
    @Autowired
    private ProductRepository productRepository;
    
    /**
     * 获取商品详情
     */
    @Transactional(readOnly = true)
    public ProductDTO getProductById(Long productId) {
        Product product = productRepository.findById(productId)
            .orElseThrow(() -> new NotFoundException(ErrorCode.PRODUCT_NOT_FOUND));
        
        // 检查商品是否在售
        if (!ProductStatus.ON_SALE.equals(product.getStatus())) {
            throw new ConflictException(ErrorCode.PRODUCT_OFF_SALE);
        }
        
        return ProductMapper.INSTANCE.toDTO(product);
    }
    
    /**
     * 创建订单 - 检查库存
     */
    public OrderDTO createOrder(Long buyerId, CreateOrderRequest request) {
        Product product = productRepository.findById(request.getProductId())
            .orElseThrow(() -> new NotFoundException(ErrorCode.PRODUCT_NOT_FOUND));
        
        // 检查库存
        if (product.getStock() < request.getQuantity()) {
            throw new ConflictException(ErrorCode.PRODUCT_OUT_OF_STOCK);
        }
        
        // 检查是否允许购买
        if (product.getSellerId().equals(buyerId)) {
            throw new ForbiddenException(ErrorCode.SELF_PURCHASE_DENIED);
        }
        
        // ... 继续创建订单逻辑
    }
}
```

## 2. 后端日志体系

### 2.1 设计目标

- **分层记录**: HTTP → AOP → Business → Exception，每层记录不同粒度
- **文件分离**: INFO 和 ERROR 日志分开存储，便于问题排查
- **异步写入**: 使用 AsyncAppender 提升性能
- **环境隔离**: dev/prod/test 环境不同配置

### 2.2 日志分层架构

```
┌─────────────────────────────────────────────────────────┐
│  HTTP 层 (RequestLoggingInterceptor)                     │
│  - 记录请求方法、URI、状态码、耗时                       │
│  - INFO 级别                                              │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  AOP 层 (LogAspect)                                      │
│  - Controller 方法：INFO（进入/离开/耗时）                │
│  - Service 方法：DEBUG（进入/离开/参数/返回值）           │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  业务层 (LogUtils / log.info)                           │
│  - 关键业务操作：INFO                                    │
│  - 审计日志：INFO                                        │
│  - 性能日志：DEBUG/WARN                                  │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  异常层 (GlobalExceptionHandler)                         │
│  - 业务异常：WARN                                        │
│  - 系统异常：ERROR + 堆栈跟踪                            │
└─────────────────────────────────────────────────────────┘
```

#### 2.3.2 LogAspect.java - AOP 日志切面

```java
package com.aisale.backend.aspect;

import com.aisale.backend.util.LogUtils;
import lombok.extern.slf4j.Slf4j;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Pointcut;
import org.springframework.stereotype.Component;

@Slf4j
@Aspect
@Component
public class LogAspect {

    /**
     * Controller 层切面 - INFO 级别
     */
    @Pointcut("execution(* com.aisale.backend.controller..*.*(..))")
    public void controllerLayer() {}

    /**
     * Service 层切面 - DEBUG 级别
     */
    @Pointcut("execution(* com.aisale.backend.service..*.*(..))")
    public void serviceLayer() {}

    /**
     * Controller 方法日志
     */
    @Around("controllerLayer()")
    public Object logController(ProceedingJoinPoint pjp) throws Throwable {
        String className = pjp.getTarget().getClass().getSimpleName();
        String methodName = pjp.getSignature().getName();
        
        log.info("[Controller] 进入方法：{}.{} - 参数：{}", 
            className, methodName, formatArgs(pjp.getArgs()));
        
        long startTime = System.currentTimeMillis();
        try {
            Object result = pjp.proceed();
            long duration = System.currentTimeMillis() - startTime;
            
            log.info("[Controller] 离开方法：{}.{} - 耗时：{}ms", 
                className, methodName, duration);
            
            return result;
        } catch (Throwable e) {
            long duration = System.currentTimeMillis() - startTime;
            log.error("[Controller] 方法异常：{}.{} - 耗时：{}ms - 异常：{}", 
                className, methodName, duration, e.getMessage());
            throw e;
        }
    }

    /**
     * Service 方法日志
     */
    @Around("serviceLayer()")
    public Object logService(ProceedingJoinPoint pjp) throws Throwable {
        String className = pjp.getTarget().getClass().getSimpleName();
        String methodName = pjp.getSignature().getName();
        
        log.debug("[Service] 进入方法：{}.{} - 参数：{}", 
            className, methodName, formatArgs(pjp.getArgs()));
        
        long startTime = System.currentTimeMillis();
        try {
            Object result = pjp.proceed();
            long duration = System.currentTimeMillis() - startTime;
            
            log.debug("[Service] 离开方法：{}.{} - 耗时：{}ms", 
                className, methodName, duration);
            
            return result;
        } catch (Throwable e) {
            long duration = System.currentTimeMillis() - startTime;
            log.error("[Service] 方法异常：{}.{} - 耗时：{}ms - 异常：{}", 
                className, methodName, duration, e.getMessage());
            throw e;
        }
    }

    private String formatArgs(Object[] args) {
        if (args == null || args.length == 0) return "无";
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < args.length; i++) {
            if (i > 0) sb.append(", ");
            String argStr = args[i] != null ? args[i].toString() : "null";
            if (argStr.length() > 100) {
                argStr = argStr.substring(0, 100) + "...";
            }
            sb.append(argStr);
        }
        return sb.toString();
    }
}
```

### 2.4 使用示例

```java
@Service
@Slf4j
public class OrderService {
    
    /**
     * 创建订单 - 包含详细日志
     */
    @Transactional
    public OrderDTO createOrder(Long buyerId, CreateOrderRequest request) {
        log.info("创建订单 - 买家 ID: {}, 商品 ID: {}, 数量：{}", 
            buyerId, request.getProductId(), request.getQuantity());
        
        try {
            // 1. 查询商品
            Product product = productRepository.findById(request.getProductId())
                .orElseThrow(() -> {
                    log.warn("商品不存在 - 商品 ID: {}", request.getProductId());
                    return new NotFoundException(ErrorCode.PRODUCT_NOT_FOUND);
                });
            
            // 2. 检查库存
            if (product.getStock() < request.getQuantity()) {
                log.warn("库存不足 - 商品 ID: {}, 可用：{}, 需求：{}", 
                    product.getId(), product.getStock(), request.getQuantity());
                throw new ConflictException(ErrorCode.PRODUCT_OUT_OF_STOCK);
            }
            
            // 3. 创建订单
            Order order = OrderMapper.INSTANCE.toEntity(request);
            order.setBuyerId(buyerId);
            order.setStatus(OrderStatus.PENDING_PAYMENT);
            orderRepository.save(order);
            
            LogUtils.logBusinessAction("创建订单", 
                String.format("订单 ID: %d, 金额：%.2f", order.getId(), order.getTotalAmount()),
                String.valueOf(buyerId));
            
            log.info("订单创建成功 - 订单 ID: {}", order.getId());
            return OrderMapper.INSTANCE.toDTO(order);
            
        } catch (BaseException e) {
            log.error("创建订单失败 - 买家 ID: {}, 错误码：{}, 错误：{}", 
                buyerId, e.getErrorCode().getCode(), e.getMessage());
            throw e;
        } catch (Exception e) {
            log.error("创建订单异常 - 买家 ID: {}", buyerId, e);
            throw new SystemException(ErrorCode.DATABASE_ERROR, e);
        }
    }
}
```

## 3. 前端错误处理体系

### 3.1 设计目标

- **统一处理**: 所有 API 错误通过 Axios 拦截器统一处理
- **用户友好**: 错误码映射为友好的中文提示
- **自动恢复**: 特定错误（如 401）自动跳转登录
- **类型安全**: TypeScript 类型定义完整

### 3.2 错误处理流程

```
┌─────────────────────────────────────────────────────────┐
│  Vue 组件发起 API 请求                                   │

                          ↓
┌─────────────────────────────────────────────────────────┐

                          ↓

                          ↓
┌─────────────────────────────────────────────────────────┐
```

### 3.3 核心文件

```typescript
  }
  return 'warning'  // 业务错误
}
```

#### 3.3.2 errorHandler.ts - 错误处理器

```typescript
// frontend/src/utils/errorHandler.ts

import { ElMessage } from 'element-plus'
import type { ErrorResponse } from '@/api/types'
import {
  getUserFriendlyMessage,
  shouldRedirectToLogin,
  HTTP_STATUS_MAP
} from './error'
import router from '@/router'

export function handleApiError(error: ErrorResponse | unknown, context?: string) {
  // 开发环境打印错误详情
  if (import.meta.env?.DEV) {
    console.error(`[API Error]${context ? ' ' + context : ''}:`, error)
  }

  // 处理已知格式的错误响应
  if (error && typeof error === 'object' && 'code' in error) {
    const errorResponse = error as ErrorResponse
    const userMessage = getUserFriendlyMessage(
      errorResponse.code,
      errorResponse.message
    )

    // 需要跳转登录的错误
    if (shouldRedirectToLogin(errorResponse.code)) {
      ElMessage.error(userMessage)
      clearAuthAndRedirect()
      return
    }

    // 根据错误类型选择提示方式
    const messageType = getErrorType(errorResponse.code)
    if (messageType === 'error') {
      ElMessage.error(userMessage)
    } else if (messageType === 'warning') {
      ElMessage.warning(userMessage)
    } else {
      ElMessage.info(userMessage)
    }
    return
  }

  // 处理 Axios 错误
  if (error && typeof error === 'object' && 'response' in error) {
    const axiosError = error as {
      response?: { status?: number; data?: ErrorResponse }
    }
    handleHttpError(axiosError, context)
    return
  }

  // 处理未知错误
  handleUnknownError(error, context)
}

function handleHttpError(
  error: { response?: { status?: number; data?: ErrorResponse } },
  context?: string
) {
  const status = error.response?.status
  const errorData = error.response?.data

  // 优先使用后端返回的错误信息
  if (errorData?.message) {
    handleApiError(errorData, context)
    return
  }

  // 使用 HTTP 状态码映射
  if (status && HTTP_STATUS_MAP[status]) {
    const { type, message } = HTTP_STATUS_MAP[status]
    if (type === 'error') {
      ElMessage.error(message)
    } else if (type === 'warning') {
      ElMessage.warning(message)
    }
    
    if (status === 401) {
      clearAuthAndRedirect()
    }
    return
  }

  ElMessage.error('网络请求失败，请稍后重试')
}

function handleUnknownError(error: unknown, context?: string) {
  // 网络错误
  if (error instanceof TypeError && error.message.includes('fetch')) {
    ElMessage.error('网络连接失败，请检查网络设置')
    return
  }

  // 超时错误
  if (error && typeof error === 'object' && 'code' in error && 
      (error as any).code === 'ECONNABORTED') {
    ElMessage.warning('请求超时，请重试')
    return
  }

  ElMessage.error(context ? `${context}失败，请稍后重试` : '操作失败，请稍后重试')
}

function clearAuthAndRedirect() {
  localStorage.removeItem('token')
  router.replace({
    path: '/login',
    query: { redirect: encodeURIComponent(router.currentRoute.value.fullPath) }
  })
}
```

#### 3.3.3 request.ts - Axios 拦截器

```typescript
// frontend/src/utils/request.ts

import axios, { AxiosInstance, AxiosResponse } from 'axios'
import { handleApiError } from '@/utils/errorHandler'
import type { ErrorResponse } from '@/api/types'

export interface ApiResponse<T> {
  code: number
  message: string
  data: T
}

const request: AxiosInstance = axios.create({
  baseURL: '/api',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json' }
})

// 请求拦截器 - 自动添加 Token
request.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = token
    }
    return config
  },
  (error) => Promise.reject(error)
)

// 响应拦截器 - 统一错误处理
request.interceptors.response.use(
  (response: AxiosResponse<ApiResponse<unknown>>) => {
    const res = response.data
    if (res.code !== 200) {
      handleApiError({ code: res.code, message: res.message } as ErrorResponse)
      return Promise.reject(res)
    }
    return response
  },
  (error) => {
    handleApiError(error)
    return Promise.reject(error)
  }
)

export default request
```

## 4. 常见问题与解决方案

### 4.1 后端问题

#### Q1: 新增错误码后前端看不到错误消息

**症状**: 后端返回了新错误码，但前端显示"操作失败，请稍后重试"

**原因**: `ERROR_MESSAGES` 中没有配置该错误码的映射

**解决方案**:
1. 在 `backend/ErrorCode.java` 中添加错误码
2. 在 `frontend/src/utils/error.ts` 的 `ERROR_MESSAGES` 中添加映射
3. 确保前后端错误码一致

```typescript
// frontend/src/utils/error.ts
export const ERROR_MESSAGES: Record<string, string> = {
  // 添加新错误码
  'NEW_ERROR_CODE': '用户友好的错误消息'
}
```

#### Q2: 系统异常暴露了内部堆栈信息

**症状**: 生产环境返回的错误消息包含 Java 堆栈跟踪

**原因**: `GlobalExceptionHandler` 中没有区分环境

**解决方案**:
```java
@ExceptionHandler(SystemException.class)
public ResponseEntity<ErrorResponse> handleSystemException(...) {
    // 生产环境不暴露详细堆栈
    String message = isProduction() 
        ? "系统繁忙，请稍后重试" 
        : e.getMessage();
    // ...
}
```

#### Q3: 日志文件增长过快

**症状**: 日志文件几小时内达到 size cap

**原因**: 
- DEBUG 级别日志过多
- SQL 日志未关闭

**解决方案**:
1. 生产环境关闭 Hibernate SQL 日志：
```xml
<springProfile name="prod">
    <logger name="org.hibernate.SQL" level="WARN"/>
</springProfile>
```

2. 调整滚动策略：
```xml
<rollingPolicy>
    <maxHistory>7</maxHistory>  <!-- 减少保留天数 -->
    <totalSizeCap>50MB</totalSizeCap>  <!-- 减小总大小限制 -->
</rollingPolicy>
```

### 4.2 前端问题

#### Q1: TypeScript 报错 "Property 'env' does not exist"

**症状**: `import.meta.env.DEV` 报类型错误

**原因**: Vite 的 `ImportMetaEnv` 类型未声明

**解决方案**: 在 `src/env.d.ts` 中添加类型声明：
```typescript
interface ImportMetaEnv {
  readonly DEV: boolean
  readonly PROD: boolean
  readonly MODE: string
}

interface ImportMeta {
  readonly env: ImportMetaEnv
}
```

#### Q1: ElMessage[messageType] 类型错误

**症状**: `ElMessage[messageType](userMessage)` 报类型错误

**原因**: TypeScript 无法推断动态属性访问

**解决方案**: 使用条件判断代替动态索引：
```typescript
if (messageType === 'error') {
  ElMessage.error(userMessage)
} else if (messageType === 'warning') {
  ElMessage.warning(userMessage)
} else {
  ElMessage.info(userMessage)
}
```

#### Q3: 401 未跳转登录页

**症状**: Token 过期但页面没有跳转登录

**原因**: 
- `shouldRedirectToLogin` 没有包含所有认证相关错误码
- 路由器未正确导入

**解决方案**:
```typescript
// 确保包含所有认证错误码
export function shouldRedirectToLogin(code: string | number): boolean {
  return ['UNAUTHORIZED', 'TOKEN_INVALID'].includes(String(code))
}

// 确保 router 正确导入
import router from '@/router'
```
