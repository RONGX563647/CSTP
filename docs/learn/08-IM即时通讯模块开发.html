08 IM 即时通讯模块开发

前置知识: SSE（Server-Sent Events）、RabbitMQ 消息队列、WebSocket 对比

一、本章概述

本章实现用户间的即时通讯功能，使用 SSE（Server-Sent Events） 实现实时消息推送。

核心学习内容:

  • SSE vs WebSocket：为什么选择 SSE？
  • SSESessionManager：管理所有 SSE 连接
  • ChatService：消息收发业务逻辑
  • RabbitMQ：异步消息处理
  • ChatMessage 实体：消息存储

---

二、技术架构说明

2.1 为什么使用 SSE 而非 WebSocket？

对比项 SSE WebSocket
通信方向 单向（服务器→客户端） 双向
协议 HTTP 独立协议
重连机制 内置自动重连 需手动实现
实现复杂度 简单 复杂
适用场景 消息推送、通知 实时游戏、聊天

本项目选择 SSE 的原因:

  • 买家-卖家聊天场景主要是单向消息推送
  • HTTP 协议天然支持，无需额外配置
  • 内置自动重连机制
  • 实现简单，易于维护

三、SSESessionManager 连接管理

3.1 技术说明

SSESessionManager 负责管理所有活跃的 SSE 连接。

核心方法:

  • register(userId): 注册用户，返回 SseEmitter
  • remove(userId): 移除用户连接
  • sendMessage(userId, message): 向指定用户推送消息
  • isConnected(userId): 检查用户是否在线

3.2 实际源码

文件位置: backend/src/main/java/com/aisale/backend/service/SSESessionManager.java

JAVA 
package com.aisale.backend.service;

import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.web.servlet.mvc.method.annotation.SseEmitter;

import java.io.IOException;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

@Slf4j
@Service
public class SSESessionManager {

    // 存储所有活跃的 SSE 连接
    private final Map<Long, SseEmitter> sessions = new ConcurrentHashMap<>();

    /**
     * 注册用户，建立 SSE 连接
     */
    public SseEmitter register(Long userId) {
        // 超时时间 30 分钟
        SseEmitter emitter = new SseEmitter(30 * 60 * 1000L);
        sessions.put(userId, emitter);

        // 连接完成时移除
        emitter.onCompletion(() -> sessions.remove(userId));
        emitter.onTimeout(() -> sessions.remove(userId));
        emitter.onError((e) -> sessions.remove(userId));

        log.info("SSE connection established for userId={}", userId);
        return emitter;
    }

    /**
     * 移除用户连接
     */
    public void remove(Long userId) {
        SseEmitter emitter = sessions.remove(userId);
        if (emitter != null) {
            emitter.complete();
            log.info("SSE connection removed for userId={}", userId);
        }
    }

    /**
     * 向指定用户推送消息
     */
    public void sendMessage(Long userId, Object message) {
        SseEmitter emitter = sessions.get(userId);
        if (emitter != null) {
            try {
                emitter.send(SseEmitter.event()
                        .name("message")
                        .data(message));
            } catch (IOException e) {
                log.error("Failed to send SSE message to userId={}", userId, e);
                sessions.remove(userId);
            }
        }
    }

    /**
     * 检查用户是否在线
     */
    public boolean isConnected(Long userId) {
        return sessions.containsKey(userId);
    }
}

四、SSE 聊天控制器

4.1 实际源码

文件位置: backend/src/main/java/com/aisale/backend/controller/SSEChatController.java

JAVA 
package com.aisale.backend.controller;

import com.aisale.backend.service.SSESessionManager;
import com.aisale.backend.util.JwtRequestUtils;
import com.aisale.backend.util.JwtUtil;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.tags.Tag;
import jakarta.servlet.http.HttpServletRequest;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.servlet.mvc.method.annotation.SseEmitter;

@Tag(name = "SSE 聊天", description = "Server-Sent Events 聊天消息推送")
@RestController
@RequestMapping("/api/sse")
@RequiredArgsConstructor
@Slf4j
public class SSEChatController {

    private final SSESessionManager sseSessionManager;
    private final JwtRequestUtils jwtRequestUtils;
    private final JwtUtil jwtUtil;

    @Operation(summary = "建立 SSE 连接")
    @GetMapping(value = "/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public SseEmitter connect(
            @RequestParam(required = false) String token,
            HttpServletRequest request) {
        Long userId;
        if (token != null && !token.isEmpty()) {
            userId = jwtUtil.extractUserId(token);
            log.info("SSE connection request from userId={} (via URL param)", userId);
        } else {
            userId = jwtRequestUtils.getCurrentUserId(request);
            log.info("SSE connection request from userId={} (via Header)", userId);
        }
        return sseSessionManager.register(userId);
    }

    @Operation(summary = "断开 SSE 连接")
    @DeleteMapping("/chat")
    public void disconnect(HttpServletRequest request) {
        Long userId = jwtRequestUtils.getCurrentUserId(request);
        log.info("SSE disconnect request from userId={}", userId);
        sseSessionManager.remove(userId);
    }
}

五、ChatMessage 实体

5.1 实际源码

文件位置: backend/src/main/java/com/aisale/backend/entity/ChatMessage.java

JAVA 
package com.aisale.backend.entity;

import jakarta.persistence.*;
import lombok.Data;
import java.time.LocalDateTime;

@Data
@Entity
@Table(name = "chat_messages", indexes = {
    @Index(name = "idx_chat_sender", columnList = "sender_id"),
    @Index(name = "idx_chat_receiver", columnList = "receiver_id")
})
public class ChatMessage {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "sender_id", nullable = false)
    private Long senderId;

    @Column(name = "receiver_id", nullable = false)
    private Long receiverId;

    @Column(nullable = false, columnDefinition = "TEXT")
    private String content;

    @Column(name = "is_read")
    private Boolean isRead = false;

    @Column(name = "created_at")
    private LocalDateTime createdAt;

    @PrePersist
    protected void onCreate() {
        createdAt = LocalDateTime.now();
    }
}
