## 🔴 重要差异（必须注意）

### 1. 实体类名称差异

| 教程中的名称 | 实际源码名称 | 说明 |
|---|---|---|
| CheckInRecord.java | **CheckIn.java** | 签到记录实体 |
| PointTransaction.java | **PointRecord.java** | 积分记录实体 |
| UserReputation.java | **ReputationRecord.java** | 信誉记录实体 |
| ProductSearchHistory.java | **SearchHistory.java** | 搜索历史实体 |
| CheckInRecordRepository | **CheckInRepository** | 签到数据访问 |
| PointTransactionRepository | **PointRecordRepository** | 积分记录数据访问 |
| UserReputationRepository | **ReputationRecordRepository** | 信誉记录数据访问 |
| ProductSearchHistoryRepository | **SearchHistoryRepository** | 搜索历史数据访问 |

### 2. 新增的实体类（教程中未提及）

### 8. 通信方式说明

教程08中提到WebSocket，但实际项目使用的是：
- **SSE (Server-Sent Events)** - 实时消息推送
- **RabbitMQ** - 消息队列
- **SSESessionManager.java** - SSE会话管理
