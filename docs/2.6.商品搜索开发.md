## 1. 概述

### 1.1 功能简介

商品搜索模块提供了全屏搜索界面和多维度智能搜索能力，支持关键词多字段匹配、同义词扩展搜索、搜索历史管理、热门搜索推荐等功能。用户点击商品列表页的搜索框即可进入全屏搜索界面，搜索结果按相关性排序，并展示匹配来源标识。

### 1.2 功能特性

- **全屏搜索界面**：点击搜索框进入沉浸式全屏搜索体验，自动聚焦输入框
- **多字段匹配**：同时搜索商品名称、描述、标签、分类，确保全面覆盖
- **同义词扩展搜索**：内置同义词映射表，搜索"手机"也能找到包含"iPhone"、"华为"的商品
- **智能相关性排序**：综合名称匹配度、分类匹配、标签匹配、描述匹配、同义词匹配、热度等多维度评分排序
- **搜索历史管理**：自动记录用户搜索历史，支持查看和清除
- **热门搜索推荐**：基于全局搜索频次推荐热门关键词，前三名特殊标识
- **搜索建议**：输入时实时从历史和热门中过滤匹配建议
- **关键词高亮**：搜索结果中高亮显示匹配的关键词
- **匹配来源标识**：展示搜索结果的匹配类型（名称/分类/标签/描述/相关推荐）

## 2. 设计思路

### 2.1 搜索流程

```
用户点击搜索框 → 进入全屏搜索页 → 输入关键词 → 防抖400ms → 调用智能搜索API
                                                              │
                           ┌──────────────────────────────────┘
                           │
            ┌──────────────▼──────────────┐
            │    后端搜索处理流程           │
            │  1. 原始关键词DB搜索         │
            │  2. 同义词扩展搜索(结果不足时) │
            │  3. 合并去重                 │
            │  4. 多维度相关性评分          │
            │  5. 按评分排序               │
            │  6. 内存分页返回             │
            └──────────────┬──────────────┘
                           │
            ┌──────────────▼──────────────┐
            │    前端展示处理               │
            │  1. 渲染搜索结果             │
            │  2. 关键词高亮               │
            │  3. 匹配类型标签             │
            │  4. 记录搜索历史             │
            └─────────────────────────────┘
```

### 2.2 相关性评分策略

评分从以下几个维度综合计算：

| 匹配维度 | 权重范围 | 说明 |
|---------|---------|------|
| 名称完全匹配 | +200 | 关键词与商品名称完全一致 |
| 名称前缀匹配 | +150 | 商品名称以关键词开头 |
| 名称包含匹配 | +40~120 | 越靠前权重越高 |
| 分类匹配 | +60~80 | 商品分类包含关键词 |
| 标签匹配 | +45~60 | 商品标签包含关键词 |
| 描述匹配 | +25×次数 | 描述中出现关键词，最多计5次 |
| 同义词匹配 | +15~35 | 商品包含关键词的同义词 |
| 销量加权 | +sales×0.5 | 销量越高加分越多 |
| 浏览量加权 | +views×0.05 | 浏览量越高加分越多 |
| 推荐商品 | +30 | 被标记为推荐的商品 |
| 折扣商品 | +20 | 折扣低于8折的商品 |

## 3. 数据库设计

### 3.1 search_history 表

```sql
CREATE TABLE search_history (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,                    -- 用户ID
    keyword VARCHAR(255) NOT NULL,              -- 搜索关键词
    search_count INT DEFAULT 1,                 -- 搜索次数
    last_search_time DATETIME,                  -- 最后搜索时间
    INDEX idx_search_history_user (user_id),
    INDEX idx_search_history_keyword (keyword),
    INDEX idx_search_history_user_time (user_id, last_search_time DESC)
);
```

### 3.2 Product 相关表索引

已有索引（搜索相关）：
- `idx_product_name` - 商品名称索引
- `idx_product_category` - 分类索引
- `idx_product_status` - 状态索引
- `idx_product_status_sales` - 状态+销量复合索引

## 6. API 接口

### 6.1 智能搜索

```
GET /api/user/products/public/search/smart
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | String | 否 | 搜索关键词 |
| category | String | 否 | 商品分类 |
| minPrice | BigDecimal | 否 | 最低价格 |
| maxPrice | BigDecimal | 否 | 最高价格 |
| page | int | 否 | 页码（默认0） |
| size | int | 否 | 每页大小（默认10） |

响应：
```json
{
  "code": 200,
  "data": {
    "content": [
      {
        "product": { "id": 1, "name": "...", ... },
        "relevanceScore": 230.5,
        "matchType": "name"
      }
    ],
    "totalElements": 15,
    "totalPages": 2,
    "number": 0,
    "size": 10
  }
}
```

matchType 取值：
- `name` - 名称匹配
- `category` - 分类匹配
- `tag` - 标签匹配
- `description` - 描述匹配
- `synonym` - 同义词匹配（相关推荐）
- `none` - 未匹配（通过热度排序出现）

## 7. 搜索算法详解

### 7.1 多字段搜索 JPQL

```sql
SELECT DISTINCT p FROM Product p LEFT JOIN p.tags t 
WHERE p.status = :status 
  AND (:keyword IS NULL OR 
       LOWER(p.name) LIKE LOWER(CONCAT('%', :keyword, '%')) OR 
       LOWER(p.description) LIKE LOWER(CONCAT('%', :keyword, '%')) OR 
       LOWER(p.category) LIKE LOWER(CONCAT('%', :keyword, '%')) OR 
       LOWER(t) LIKE LOWER(CONCAT('%', :keyword, '%')))
  AND (:category IS NULL OR p.category = :category)
  AND (:minPrice IS NULL OR p.price >= :minPrice)
  AND (:maxPrice IS NULL OR p.price <= :maxPrice)
```

### 7.2 同义词扩展搜索流程

1. 使用原始关键词进行 DB 搜索
2. 如果结果数量不足（< 一页），触发同义词扩展
3. 从 `SYNONYM_MAP` 中查找关键词所属的同义词组
4. 逐个使用同义词进行 DB 搜索，合并去重
5. 直到结果足够或同义词用完

### 7.3 相关性评分算法

```
总分 = Σ(各关键词评分) + 热度加权 + 特殊标记加权

各关键词评分：
  名称完全匹配: +200
  名称前缀匹配: +150
  名称包含匹配: +120 - position×0.5
  名称分词前缀: +60
  名称分词包含: +40
  分类完全匹配: +80
  分类包含匹配: +60
  标签完全匹配: +60
  标签包含匹配: +45
  描述包含匹配: +25 × min(出现次数, 5)
  同义词名称匹配: +35
  同义词描述匹配: +15
  同义词标签匹配: +25

热度加权：
  销量加权: +salesCount × 0.5
  浏览量加权: +viewCount × 0.05

特殊标记：
  推荐商品: +30
  折扣商品(<8折): +20
```

## 8. 使用说明

### 8.1 用户操作流程

1. 在商品列表页点击搜索框 → 进入全屏搜索页
2. 在搜索页输入关键词 → 自动触发搜索（防抖400ms）
3. 或点击历史记录/热门搜索 → 直接搜索
4. 查看搜索结果，支持排序切换
5. 点击商品 → 进入商品详情

### 8.2 搜索技巧

- 输入简短关键词效果更好（如"手机"而非"智能手机"）
- 系统会自动扩展同义词搜索
- 搜索结果按相关性排序，最匹配的结果排在前面
- 绿色标签表示名称匹配，蓝色标签表示分类匹配等

## 9. 扩展功能

### 9.1 后续可扩展方向

1. **搜索联想词**：基于 Elasticsearch 实现实时搜索建议
2. **拼音搜索**：支持拼音输入匹配中文商品名
3. **搜索推荐**：基于用户浏览和购买历史的个性化搜索排序
4. **图片搜索**：以图搜物功能
5. **搜索统计**：搜索结果点击率、转化率等数据分析
6. **搜索过滤**：价格区间、地区、品牌等高级筛选
7. **Elasticsearch 集成**：大数据量下的全文检索引擎

### 9.2 性能优化方向

1. 搜索结果缓存（已实现热门商品缓存）
2. 数据库查询优化（索引已建立）
3. Elasticsearch 全文索引替代 LIKE 查询
4. 搜索频率限制和防爬虫
