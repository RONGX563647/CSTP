二、项目亮点

2.1 架构设计

  1. 前后端分离: 清晰的分层架构
  2. RESTful API: 标准化接口设计
  3. JWT无状态认证: 支持水平扩展
  4. AOP日志记录: 自动记录操作日志
  5. 统一异常处理: 全局异常捕获

2.2 安全机制

  1. 密码加密: BCrypt单向加密
  2. JWT验证: Token过期机制
  3. 权限控制: 角色权限分级
  4. CORS配置: 跨域安全控制
  5. 参数校验: 输入验证防护

2.3 性能优化

  1. 分页查询: 避免大数据量查询
  2. 懒加载: 避免N+1查询
  3. 索引优化: 数据库索引提升查询性能
  4. 连接池: HikariCP连接池管理
  5. 多级缓存: Redis + Caffeine（预留）

五、常见问题FAQ

Q1: 如何修改后端端口？

A: 修改 application.yml 中的 server.port

Q2: 如何切换数据库？

A: 修改 application.yml 中的数据源配置，并引入对应驱动

Q3: 如何部署到服务器？

A: 使用Docker Compose一键部署，参考教程13

Q4: 如何实现Refresh Token？

A: 添加refreshToken字段，实现单独的刷新接口

Q5: 如何集成微信支付？

A: 使用微信支付SDK，实现统一下单、支付回调等接口
