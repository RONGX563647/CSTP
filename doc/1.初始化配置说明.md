### 1.3 配置文件

#### 环境变量（`.env`）

在 `backend/` 目录下创建 `.env` 文件：

```env
# JWT 配置（必需，至少 32 字符）
JWT_SECRET=your-secret-key-at-least-32-characters-long

# OpenAI 配置
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
OPENAI_BASE_URL=https://api.openai.com

# 数据库配置（可选，默认 H2）
SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/aisale
SPRING_DATASOURCE_USERNAME=postgres
SPRING_DATASOURCE_PASSWORD=your-password
```

#### application.yml 核心配置

```yaml
server:
  port: 8090

spring:
  application:
    name: aisale-backend
  
  # 数据库配置
  datasource:
    url: jdbc:h2:mem:aisale;DB_CLOSE_DELAY=-1
    username: sa
    password: 
    driver-class-name: org.h2.Driver
  
  # JPA 配置
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        format_sql: true
  
  # AI 配置
  ai:
    openai:
      api-key: ${OPENAI_API_KEY:default-key}
      base-url: ${OPENAI_BASE_URL:https://api.openai.com}

# Swagger/Knife4j 配置
springdoc:
  swagger-ui:
    path: /swagger-ui.html
  api-docs:
    path: /v3/api-docs

knife4j:
  enable: true
  setting:
    language: zh_cn

# 热部署配置（开发环境）
spring:
  devtools:
    restart:
      enabled: true
      additional-paths: src/main/java
```

> 完整配置请查看 `application-dev.yml` 文件。

## 四、常见问题

### Q1: 启动时报 JWT_SECRET 错误
确保 `.env` 文件中 `JWT_SECRET` 至少 32 个字符

### Q2: 前端无法连接后端
检查 `VITE_API_BASE_URL` 配置，确保后端已启动

### Q3: 数据库连接失败
- 开发环境：使用默认 H2 配置
- 生产环境：检查 PostgreSQL 是否运行，端口 5432 是否开放

### Q4: Maven 依赖下载失败
配置国内镜像，在 `pom.xml` 添加：
```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### Q5: npm install 失败
尝试使用淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

## 六、启动问题详解

### 6.1 问题一：OpenAI API Key 未配置

**错误信息**：
```
org.springframework.beans.factory.BeanCreationException: 
Error creating bean with name 'openAiChatModel': 
Failed to instantiate [org.springframework.ai.openai.OpenAiChatModel]: 
Factory method 'openAiChatModel' threw exception with message: 
OpenAI API key must be set.
```

**原因分析**：
Spring AI 在启动时会自动配置 `OpenAiChatModel` Bean，并强制要求配置 API Key。如果 `.env` 文件中使用的是占位符（如 `your-openai-api-key`），则验证会失败。

**解决方案**：
在 `application.yml` 或 `application-dev.yml` 中配置默认值：
```yaml
spring:
  ai:
    openai:
      api-key: ${OPENAI_API_KEY:test-key-for-dev}
      chat:
        enabled: ${AI_CHAT_ENABLED:false}  # 开发环境可设为 false
```

---

### 6.2 问题二：访问接口需要密码认证

**错误信息**：
```
Using generated security password: 83a7b489-1de3-4e8f-8f9b-bb08f1923cb4
This generated password is for development use only.
```

**原因分析**：
项目引入了 `spring-boot-starter-security` 依赖后，Spring Security 会自动启用。默认情况下，所有 HTTP 请求都需要认证，并会在控制台生成一个随机密码。

**解决方案**：
创建 `SecurityConfig` 配置类，根据 Profile 区分开发和生产环境的安全策略：

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    @Profile("dev")  // 开发环境：免认证
    public SecurityFilterChain devSecurityFilterChain(HttpSecurity http) throws Exception {
        return http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth.anyRequest().permitAll())
            .headers(headers -> headers.frameOptions(frame -> frame.disable()))
            .build();
    }

    @Bean
    @Profile("!dev")  // 生产环境：需要认证
    public SecurityFilterChain prodSecurityFilterChain(HttpSecurity http) throws Exception {
        return http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth.anyRequest().authenticated())
            .httpBasic(Customizer.withDefaults())
            .build();
    }
}
```

**启动时必须指定 profile**：
```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

### 7.2 SecurityConfig.java - 安全配置

**文件位置**：`backend/src/main/java/com/aisale/backend/config/SecurityConfig.java`

**作用**：
- 配置 HTTP 请求的认证授权策略
- 根据 Profile 切换开发和生产环境的安全级别
- 配置 H2 控制台的 frame 访问权限
- 配置 Swagger 文档的访问权限

**完整实现**：
```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    /**
     * 开发环境安全配置
     * - 开放所有接口，无需认证
     * - 允许 H2 Console 使用 frame（嵌入式数据库界面需要）
     * - 禁用 CSRF（开发环境不需要）
     */
    @Bean
    @Profile("dev")
    public SecurityFilterChain devSecurityFilterChain(HttpSecurity http) throws Exception {
        return http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/h2-console/**").permitAll()
                .requestMatchers("/swagger-ui/**", "/swagger-ui.html").permitAll()
                .requestMatchers("/v3/api-docs/**").permitAll()
                .anyRequest().permitAll()
            )
            .headers(headers -> headers.frameOptions(frame -> frame.disable()))
            .build();
    }

    /**
     * 生产环境安全配置
     * - 所有接口需要认证
     * - 禁用 H2 Console（生产环境不允许访问）
     * - 保留 Swagger 但需要认证后访问
     */
    @Bean
    @Profile("!dev")
    public SecurityFilterChain prodSecurityFilterChain(HttpSecurity http) throws Exception {
        return http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/h2-console/**").denyAll()
                .requestMatchers("/swagger-ui/**", "/v3/api-docs/**").authenticated()
                .anyRequest().authenticated()
            )
            .httpBasic(Customizer.withDefaults())
            .build();
    }
}
```

**配置说明**：

| 注解/方法 | 说明 |
|-----------|------|
| `@Configuration` | 标记为 Spring 配置类 |
| `@EnableWebSecurity` | 启用 Spring Security 的 Web 安全支持 |
| `@Profile("dev")` | 仅在 dev profile 激活时加载该 Bean |
| `@Profile("!dev")` | 在非 dev profile 时加载该 Bean |
| `SecurityFilterChain` | 定义安全过滤链，控制请求如何被处理 |
| `csrf().disable()` | 禁用 CSRF 防护（API 项目通常不需要） |
| `frameOptions().disable()` | 允许 H2 Console 在 iframe 中显示 |
